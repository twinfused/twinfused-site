## The challenge

Most air conditioners in Mauritius are legacy split units with no connectivity. They can easily keep running in an empty room, and nobody can see how much power they really use.

## The solution

We made the existing AC units smart **without replacing them**. **IR blasters** send the same commands as the original remote, **door sensors** show when a room is in use, and **power consumption meters** on each AC measure what it actually draws.

Automation rules combine these signals. Based on occupancy, the system can switch a unit off or adjust its temperature so it never runs unnecessarily in an empty room. Users can still change the temperature and state themselves, or leave the automation in charge.

## The result

AC that runs only when it is needed, clear visibility of the power each unit consumes, and no need to replace working equipment to get there.
